# SZU Score Helper

深圳大学成绩查询小助手。

## 当前状态

学校系统近期已调整，原先用于辅助查看绩点的方式已经失效。

因此，当前版本**暂时不能继续查询或推断绩点**。如果继续使用，可能只能看到学校页面当前已经正常开放展示的内容，不能保证还能查到隐藏或未开放的信息。

项目暂时保留代码和历史版本，后续如果有新的可用方式再更新。

## 原功能说明

本工具原本用于更方便地查看课程成绩、学分和绩点：

- 图形界面，双击即可使用。
- 自动打开浏览器，由用户手动完成学校统一认证登录。
- 在本机读取登录状态并展示成绩结果。
- 汇总总学分和平均绩点。
- 支持 exe 直接运行，也支持源码运行。

## 使用建议

目前不建议继续下载或使用旧版 exe 查询绩点。

如果只是查看学校已经开放的成绩，建议直接以学校官方页面为准。

## 源码运行

如果你仍想查看或测试源码，需要 Python 3.8+。

安装依赖：

```bash
pip install requests playwright
```

运行：

```bash
python GUI.py
```

## 打包 exe

使用 PyInstaller：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "深大查分助手" GUI.py
```

打包完成后，文件在：

```text
dist/深大查分助手.exe
```

## 注意事项

- 本工具只在本机运行，不会上传账号、密码或登录信息。
- 登录时请确认浏览器页面是学校统一认证页面。
- 学校页面调整后，旧版本可能失效。
- 请勿高频刷新或频繁请求学校系统。
